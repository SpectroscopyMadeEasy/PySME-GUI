Numerics
How finely the wavelength grid is refined

PySME computes the spectrum on a wavelength grid of its own. It computes a point halfway between two neighbours, and if that differs from a straight line between them by more than about accwi times the continuum, it splits the interval again.

Smaller: more points, more accurate, slower. It is not a limit on the error of the final spectrum. It also matters with a fixed Step or an observed spectrum, whose points are interpolated from this grid. PySME's default is 0.003.

Which weak lines and line wings count

accrt is compared with the ratio of a line's opacity to the continuum opacity. A line that stays below it at its centre, in every layer of the atmosphere, is left out. Any other line is computed only as far into its wings as it stays above it.

Smaller: more weak lines and wider wings are included, slower. It is a threshold on opacity, not a limit on the error of the spectrum. PySME's default is 0.0001.

μ values

The intensity is computed at these angles, μ = cos θ: 1 at the centre of the stellar disc, towards 0 at the limb. Each value stands for a ring of the disc, and the spectrum is the flux of the whole disc added up from the rings. Separate values with commas or spaces.

With a single value the result is the intensity at that angle (times π when not normalised), and v sin i is not applied. Changing the number of angles above puts PySME's default values back.

Synthesize or fit a spectrum

Start from the built-in example, open an SME file, or set up your own star.

  1. Load a VALD line list.
  2. Set the stellar parameters and a wavelength range, or import an observation.
  3. Press Synthesize. To fit, choose free parameters in the Fit tab.
