Synthesize or fit a spectrum

Start from the built-in example, open an SME file, or set up your own star.

  1. Load a VALD line list.
  2. Set the stellar parameters and a wavelength range, or import an observation.
  3. Press Synthesize. To fit, choose free parameters in the Fit tab.

Ready to synthesize

Press the button, or ⌘↩. The first run with a model grid downloads it.
